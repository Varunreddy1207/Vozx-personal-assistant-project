# VOZX AI - Futuristic Mobile App Interface

An intelligent personal assistant mobile web interface built with a deep black, futuristic neon aesthetic based on the provided reference design.

## Features

- **Deep Black & Futuristic Neon Aesthetic**: Precision-tuned contrast with deep pure black (`#000000`), electric cyan (`#38bdf8`), and neon purple (`#c084fc`) glows.
- **Header Section**:
  - Brand identity: "VOZX AI" with an active glowing cyan pulsing dot.
  - User profile badge: Minimal circular silhouette button with subtle dark blue gradient.
- **Hero Section**:
  - Center 3D spherical energy orb with wispy glowing cyan and purple energy swirls, breathing aura, and interactive canvas particles.
  - User greeting: "Hello Varun".
  - Main prompt: "How can I help you today?".
- **Grid Menu Section (4x2)**:
  - Row 1: **Voice Mode** (mic), **Ask AI** (chat bubble), **PDF Assistant** (doc), **Memory** (brain).
  - Row 2: **Planner** (calendar), **Notes** (pencil), **Files** (folder), **Settings** (gear).
  - Tactile micro-interactions and interactive modal drawer on click.
- **Recent Conversations Section**:
  - Rounded container with "Recent Conversations" header and "See all >" trigger.
  - Item 1: **AI Car Project** (Blue circle badge + car icon • 2h ago).
  - Item 2: **PrintFlow Backend** (Purple circle badge + doc icon • 5h ago).
  - Item 3: **Gym Nutrition Plan** (Green circle badge + dumbbell icon • 1d ago).
- **Sticky Glowing Bottom Input Bar**:
  - Pill-shaped input container with a neon cyan glowing border and diffuse ambient backdrop glow.
  - "Ask anything..." placeholder.
  - Audio wave equalizer icon with animated voice bars.

## How to Run & Preview

### Option 1: Direct File
Simply open `index.html` in any modern web browser (Chrome, Edge, Safari, Firefox).

### Option 2: Local Python Web Server
From this project directory, run:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.
